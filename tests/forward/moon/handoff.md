# 项目续接

- 本轮目标与范围：完成原创知识漫画的选题入口、可朗读口播、关键画面、逐状态计划与制作交接；用户自行配音、BGM和组合。现在不作画、不生成视频。
- 当前阶段与版本：moon-v01-text-handoff，文字制作计划。计划输出3144帧、24fps、暂定131秒；21个主状态、23个素材登记、22个独立画稿ID。没有任何实际输出帧或图稿。
- 受众问题、结论、理解题：白天为什么也能见月亮；反射太阳光、与太阳可同在当地天空、且要能从亮背景辨出；理解题为新月何以通常不可见，答案见topic-decision.md。
- 实际文件：README.md为入口；topic-decision.md为入口比较与包装；narration.md为口播；facts-and-sources.md为事实卡；episode-plan.json为主计划；visual-and-states.md为状态卡、锚点与提示词；exposure.csv为场内及全片暂定帧段；reading-and-tools.md与read-audit.json为实际读取记录；validation-handoff.json与validation-review.md为检查结果。测试执行时的build_deliverables.py未随归档收录，归档交付为已生成的文字、JSON与CSV。
- 已核验与缺口：C01至C06已用机构网页及明确几何推导核验，M01为虚构。不掌握本地观测时刻，不给当天找月亮建议。未来图片的光线、地平线、相位还须实际检查。
- 角色与风格不变量：用户自创圆脸小猫。原图未给，不定毛色、耳尾、服装或名字；下一绘画阶段要先拿到身份图。简化轮廓、大色块、明确态度；夸张自信、肩手和受挫，科学关系不变。参考作者证据只作研究，不直接进成片。
