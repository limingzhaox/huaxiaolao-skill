# 白天月亮知识漫画 · 文字制作交接

moon-v01-text-handoff。本轮完成选题、口播、关键画面与状态规格；没有作画或视频。用户自行配音和BGM。

先读[选题入口](topic-decision.md)与[可朗读口播](narration.md)。制作端以[主计划](episode-plan.json)为准，结合[状态卡与素材规格](visual-and-states.md)、[暂定曝光表](exposure.csv)和[续接](handoff.md)执行。事实依据见[事实卡](facts-and-sources.md)，实际阅读范围见[记录](reading-and-tools.md)与[机器审计](read-audit.json)，检查结果见[handoff结果](validation-handoff.json)和[说明](validation-review.md)。

采用入口是小猫拿排班表催月亮下班。解释顺序为反射太阳光、当地天空可同时容纳太阳月亮、亮背景中的辨认条件，再用新月反例检查。竖版1080×1920，中间960×640横向舞台。

计划暂排131秒、3144个输出帧、21个主状态、23项素材登记、22个独立画稿ID。所有图像仍planned；数量表示需要准备的规格，不是已生成张数。实际配音到来后重排持帧与字幕。

未解决输入是用户圆脸小猫原图、实际配音和最终发布平台。原角色配色、耳尾和服饰不擅自定稿。风格与成片均未获用户认可，受众效果尚未验证。
