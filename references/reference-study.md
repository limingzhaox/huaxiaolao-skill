# 新增样本时怎样做深度拆解

现有两条深拆和精选图片已经可以支持复用，不需要每次重新抓视频。只有用户要新增研究时才做以下工作。研究作者表达与研究科学事实分开，不把参考片当唯一科学来源。

## 取得可定位的材料

记录作者主页、具体作品URL、取得日期、标题、平台、公开热度快照、选择理由、实际可访问版本和音轨情况。高热度要说明相对哪个范围，不能把搜索到的两条叫“最高两条”。短链打不开，可以寻找作者其他官方发布版本，但不能声称版本完全一致。

仅使用可正常访问并获授权的材料，不绕过登录、付费或安全限制。不能取得原片时，用本包图片研究已覆盖的现象，列出不足，不伪造逐帧结果。

保留技术索引，包括尺寸、帧率、帧数、实际时间戳PTS和帧号起点。恒定帧率可以用F/fps作名义导航；变帧率须用实际PTS。研究源帧号与原创场景帧号放在不同表，不能混用。

## 两轮查看，分别回答两类问题

先按语义划段，记录每段的观众问题、增加的信息、角色处境、下一问、开头与结尾锚点。导航图帮助找段落，但不是全片逐帧审阅。字幕只能证明画面可见文字，未听音频时不能写“作者用某语气说”。

再选有价值的变化窗口，逐输出帧看局部。通常包括突然反应、接触形变、角色进出、从无到有、图解替换和一段持帧。窗口要包含变化前、变化发生和结果持住，不能只截一个爆点解释因果。

自动图差或感知哈希可以帮助发现候选切点。它们不能判断科学因果、笑点、绘制方式，也可能漏掉小表情或被字幕变化误导。相邻帧相同也有“等待阅读”的意义，记录持帧区间，不给每个重复帧编造新动作。

## 一条可复核的标注

```text
sample_id / source_frame / PTS / source_url / file_hash
viewed = 本次实际打开 / 历史记录 / 未看
visible = 人物、道具、字幕和变化的直接描述
operation = CUT / HOLD / FACE_SWAP / POSE_SWAP / SYMBOL / DIAGRAM / DRAW_STEP / REVEAL
trigger = 能定位的前态；没有充分证据则写待定
interpretation = 对阅读、态度或理解的作用
transfer = 换一个知识关系后的原创方案
boundary = 本图或本窗口不能证明的结论
```

同一帧允许多个操作标签。标签是分析语言，不是作者工程文件里的图层名。独立轮廓、清线、色块阶段能支持DRAW_STEP；单张图被擦出只支持REVEAL，不能凭成片反推具体软件或录屏工序。

## 把研究变成可用规则

每个机制保留一组图证、正确时序、直接观察、解释、迁移和边界。优先问“为什么此处需要这个变化”，再问“怎样实现”。例如把挤出画框抽象成比较条件不充分，而非记成所有主题都让角色挤进角落。

规则写成条件句。“当两个对象无法在共同尺度下比较，可先把比较困难画成处境，再建立可靠共同标尺。”不要写成“每条必须有夸张反应、元叙事和反转”。

热度只说明样本选择，不能证明某个手法造成播放。受众喜欢、读懂、愿意转发是不同结果，需要各自证据。没有测量时把它们写为创作假设。

## 交付覆盖范围

列实际人工看过的帧/连续区间、只自动处理的范围、未覆盖段落与未听音轨。输出精选证据和清单，使下一AI能在本包内核对关键结论。视频全帧解码成功不能升级为人工全片逐帧深拆。

新增证据后修改研究文件、索引和manifest，并重新检查本地链接及哈希。发现矛盾时保留修正理由，更新依赖规则，避免旧错误在续接中重新传播。
