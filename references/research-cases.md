## 两条视频的结构怎样工作

花生用“熟悉食物，却未必知道它怎样生长”的落差进入。问题与解释保持同一对象，名字、位置、连接路径与生长条件逐步展开。虎鲸让知识对象想证明自己厉害，比较对象反复回场，能力、代价和群体关系因此变成它的处境。

可迁移的核心是：观众问题→可核实的新信息→角色想做的事→条件/阻碍→可见后果→反应→下一问。它是研究提炼的决策链，不是作者披露的固定流程。

## 八组可以复用的具体机制

### 1. 对戏失控与后来的反例，必须区分顺序

花生F416仍是前组表情，F417右侧演员爆发、其他角色同时受惊。F540字幕提到原剧本，F570才明确出现“其他果实也来自花”的反例。旧笔记曾把F417写成被反例激怒，后续原帧复核已纠正。

直接观察是成组换脸与随后反例。解释是讲述者试图维护一个不充分说明，却先遇到演员脾气、后遇到逻辑异议。原创可以让解释者有当前目标，让反例对象有发言资格；不要复制三食物戏服和台词，更不能把后到的触发提前。

### 2. 挤进画框，让比较先成为处境

虎鲸F568占大画面，鲨鱼挤角落；F629两者完整进入。后续共同标尺才负责精确比较。构图先让观众感到“看不全”，角色不满有可见原因。

原创用画框、容器或共同尺度让比较发生，而非两张立绘贴数字。喜剧里画得大不证明真实比例，最终比较仍须可核实。锚点不能证明全部拉远曲线。

### 3. 熟悉道具承载关系

虎鲸F1800读兵书建立“策略”类比；F2410和F2475用老师、学生、黑板建立经验传递。几件物件和位置就够，不必完整室内风景。

原创先列关系映射，再选最少道具。拟人课堂与兵书是表达，不能当动物具有同样人类心理的证据。

### 4. 把推论用过头的结果画出来

花生F3235仍在采收，F3254突然拉成夸张地下深度，后面小人抱怨。放大的是“深度”，任务是“采收”，不宜笼统归为身体拉伸。

原创找一条确会被过度推广的推论，只放大一个维度，使代价落入具体任务。假设明确，不给荒诞距离写真实数值。

### 5. 条件对照落在承受者身上

花生F3420–F3690保留太阳、土层与植株，带脸的果针想留在地面，后续状态展示后果。拟人目标使条件影响成为处境，稳定底图让观众追踪。

原创让实际受条件作用的对象获得小愿望，别让旁边讲解员单独卖萌。植物“任性”不是发育原因。所列离散锚点不能证明每一步连续运动。

### 6. 难以承受的感觉外化

游隼F6400乱羽大眼、F6500汗与小魂符号升级失控，F6550加入从容游隼作比较，F6600回到鼻孔局部资料。夸张的负担为后面结构解释设置问题。

原创可先示范失败负担，再对照稳定状态，最后回到结构证据。小魂不是生理结果，搞笑画面不能冒充实验。

### 7. 力度用姿态和受击结果表达

虎鲸动作段用拍、砸、撞、扫的不同姿态，受击者压扁或飞出，配方向线与爆点。末尾旁观反应把动作收住。不是同图持续放大缩小。

原创分清准备、接触、受力结果、反应；必要时补中间姿态。效果线有作用位置，不能替代缺失接触。

### 8. 第二次反应改写刚建立的预期

虎鲸F4414大鲸托小动物，F4443小动物被甩走，旁观者姿态改变。救援形成温情预期，下一状态改写它。

原创让结果刚被看懂，再给符合角色设定的新变化。不能把故事化救援动机直接写成动物行为定论。

## 连续帧窗口：三种不同操作

花生40–44秒窗口先在F1207直接切完整植株，再在F1237直接切局部，F1263标注到达，F1287局部替换。所查窗口没有逐笔长线，不标成手绘生长。

虎鲸开头0.6–4秒有主体持住、两组装饰交替，以及完整夸张表情/姿态切换。装饰交替与新动作要分别计数。

虎鲸F2169–2177确有短促构建：

| 帧 | 可见新状态 |
|---|---|
| 2169 | 一段主轮廓 |
| 2170 | 身体轮廓完成 |
| 2171 | 一侧眼眶和鳍线 |
| 2172 | 另一侧眼眶 |
| 2173 | 瞳孔、嘴、皱纹等细节 |
| 2174 | 清除穿过眼眶的交叉轮廓 |
| 2175 | 大面积填黑 |
| 2176 | 加白斑，完成图 |
| 2177 | 持住完成图 |

成片能证明状态顺序，不能证明作者软件、绑定、遮罩或是否录屏。制作原创时先画最终图，再准备真实轮廓/表情/色块阶段是一项可复用方案，不冒称作者实际做法。

## 继续增加研究时

记录来源版本和实际PTS；先导航找变化，再选连续窗口；逐张查看并注明范围。记录四列“观察/解释/迁移/边界”，不把OCR、自动差分、继承标签当独立人工审阅。不为凑逐帧数量给重复画面编新动作。

这份研究留下的是可测试的创作假设。是否好看需实际作品核对，是否吸引受众需实际数据；没有这两类证据，不升级结论。
