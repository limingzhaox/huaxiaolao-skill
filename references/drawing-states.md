# 逐状态绘画与素材交付

## 从知识动词到画稿

先定镜头要看懂的关系，再定演员动作和新增状态。单张最终图清楚之后，才按动作理解需要补差分。若用户已要求连续推进，先产出可核对画面并继续授权范围，不另设逐张审批流程；风格未被认可仍照实标注。

一张状态卡至少记录：镜头/状态ID、对应口播句、知识命题、角色目标、触发、前后反差、变化区域、不变量、接触点、需要的符号、知识回收点、文件状态。完整字段结构见[计划样例](../assets/episode-plan.example.json)。

## 什么时候真的需要重画

| 变化 | 合适资产 | 不足的替代 |
|---|---|---|
| 视线、眼皮、嘴 | 局部表情或整姿态差分 | 任意眨眼循环 |
| 指向、抓住、蓄力 | 新手势/肩臂/身体姿态 | 同一张图左右摆 |
| 受力、接触、变形 | 接触前、接触、受力、结果、必要恢复 | 整图统一拉宽缩小 |
| 进入新场景 | 新构图或真实线稿/色块阶段 | 随意全屏擦入冒充逐笔绘画 |
| 解释路径 | 稳定底图加部件、指示、标签 | 每张全图随机重生成 |
| 情绪落地 | 触发后的反应状态与持帧 | 只有快切，没有读懂后果的时间 |

不是所有动作都补等量中间稿。夸张反应可硬切；抓、推、碰撞若看不出接触，应补关键状态。速度线辅助力度，不能替代缺失接触。

## 实际生成的输入组织

用当前可用图像生成/编辑工具；存在环境图像skill时遵循其调用要求。不要为了路径和批量管理擅自改成收费API。只有代码能力时交提示词和状态需求，不伪造绘画产物。

每次清楚标记输入图角色：身份参考、风格参考、编辑目标、上一状态。参考作者图片是风格/研究证据，不是原创视频的直接画面素材。

透明角色差分的提示词结构可用如下模板。整场景、背景与科学图按各自职责修改交付项，不把“不要背景”套到需要场景的画稿。

```text
用途与状态ID
输入图1是角色身份；图2是上一状态；图3只参考线条和色块。
保持：轮廓识别点、衣服色块、机位、脚底基线、道具锚点。
只改：听到哪条信息后，视线/眼口/肩手怎样变化。
动作：准备、接触或结果中的具体一拍，朝向与力度明确。
绘画：大色块、经济轮廓、明确态度，减少软渐变和细碎材质。
交付：一张完整姿态，或指定对齐局部；留安全边距，真透明Alpha。
不要：背景、文字、大气泡、额外道具、随机装饰或多格拼图。
通过条件：身份一致，变化区域清楚，接触和事实关系成立。
```

先核对身份、构图和知识关系，再扩展差分。工具没按提示词做到平涂，不能只因提示词写了“flat”就判通过；在修改单里点名实际渐变或贴纸感。

## 图层与锚点

优先拆背景、完整角色姿态、可替换表情/手势、道具、前景遮挡、符号、文字。完整姿态切换常比过度拆四肢更自然，不强制木偶绑定。

透明PNG记录画布尺寸、Alpha、主体边界、脚底锚点、手与道具接触点。贴图前爪可以用相同源图像素重新叠在道具上，遮挡层与道具分开。检查握持位置、道具角度、前后遮挡和手指是否跟随。

同一镜头的脚底、机位和比例一般保持；因蓄力、跃起等改变时写理由。不要仅按整张PNG外框对齐，透明边距变化会造成角色跳动。旋转道具要围绕握持点，不能绕图片中心让手漂移。

科学图文字、数字和箭头独立制作。原生几何确实适合简单图解时可用代码，但不能用硬质工厂模型假装柔软器官、用无依据形变假装仿真。

科学图的坐标也要复核是否满足想表达的关系。光路不能穿过不透明主体，受光点应同时满足光源和观察方向；当地地平线要经过观察点并垂直天顶。先写这些不变量，再选锚点并复算，出图后再看实际图。ID、路径和帧区间全部通过，也发现不了这种图解错误；简单几何检查不冒称物理仿真。

## 版本和核对

命名建议`S02_B_ring_v02.png`，镜头、状态、角色、版本分开。保存提示词、实际参考、生成工具、修改目标和结果。保留已采用版本，避免覆盖后无法对照。

核对按视觉问题分层：身份→动作/接触→事实→风格→排布。用户愿意自行核对时交实际结果与未确认状态，不额外拖延艺术审查。文件存在、画图完成和画风认可仍分别记录。

正式交付包含真实PNG、图层职责、透明信息、锚点、对应状态和口播ID。缺的资产列为planned，不能用“已有完整动画”描述。
